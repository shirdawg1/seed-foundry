# Seed Foundry

Seed Foundry is an iOS app that helps aspiring entrepreneurs turn early-stage ideas into structured startup opportunities. Users capture a raw idea and work through guided, AI-enabled workflows — market sizing, pricing & risk, and validation — to move it toward something concrete.

## Try it
Join the TestFlight beta: https://testflight.apple.com/join/PC8KbDtV

## What it does
- Capture a business idea and generate AI-driven market, pricing, and validation feedback
- Generate AI visual concepts for the idea
- Organize and revisit multiple startup "seeds" in one workspace

## Tech stack
- **Frontend:** React Native + Expo Router, TypeScript
- **Backend:** Node.js / Express, deployed on Render
- **AI:** OpenAI API integration for market analysis and image generation

Self-taught and built solo, from concept to a working TestFlight beta in about four months.

## About this repo
This repo contains the frontend app code. The backend (which handles API keys and server logic) is kept in a separate private repo for security.
